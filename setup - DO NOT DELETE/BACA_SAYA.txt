=======================================================
FOLDER SETUP PENGATURAN DEFAULT (DO NOT DELETE)
=======================================================

Folder ini berisi file pengaturan default untuk Google SERP Scanner.
JANGAN HAPUS FOLDER INI!

File di dalam folder ini:
1. keywords.txt   : Daftar kata kunci pencarian Google bawaan (1 baris per kata kunci).
2. blacklist.txt  : Daftar domain web & nama bisnis/brand sendiri (misal: mesinprinting.id, ANUGRAH SUPPLY MANDIRI) yang TIDAK boleh diklik saat mode klik iklan aktif. Semua model iklan Google (Search, Maps, Shopping) otomatis terlindungi.
3. config.txt     : Konfigurasi tambahan (jeda waktu, mode headless, target domain kompetitor, opsi lewati iklan maps).

Anda dapat mengedit file-file di atas langsung menggunakan Notepad.
Pengaturan akan otomatis dimuat oleh aplikasi setiap kali dijalankan.
